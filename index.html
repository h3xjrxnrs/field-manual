      Model notes, sources & controls

      Each square represents a 3 m foundation. Coverage uses planter slot centers on the same floor, not physics, wall occlusion, vertical reach or collision detection. A covered slot is not a guarantee of 100% plant condition. Sprinkler demand uses 2 mL/s per active sprinkler and source limits are conservative. Power assignments are logical groups, not a full electrical-port simulator; build the distribution and check in-game active usage. Batteries are assumed fully charged for autonomy estimates. Construction blocks, wire/hose tools and blueprint research are not included in the equipment cost. Device costs and rates are editable in the catalog in js/farm-data.js. No live game connection.

      Keyboard: 1 Select, 2 Place, 3 Move, 4 Erase; Delete removes selection; Ctrl+Z / Ctrl+Shift+Z undo/redo while the editor is focused. Click items in Select mode or use the inspector item list.

      References: Facepunch Farming Basics · Rustrician Electrical Handbook · Large Planter Box recipe · Small planter · Composter. Planning data reviewed November 2026.

      01 / POWER

      Start at the source.

      Generation charges a battery; the battery supplies the circuit. Output rating limits what can run at once.

      02 / DISTRIBUTION

      Follow the ports.

      Branch Out reserves a set amount. Power Out carries the remainder. Splitters share power among connected outputs.

      03 / AUTOMATION

      Keep networks separate.

      Wire Tool carries power and signals. Pipe Tool moves items via powered conveyors. Hose Tool carries water.

      Reference & version notes

      PC Rust, vanilla-oriented; community and official references reviewed November 2026. This is a handbook, not a live circuit simulator. Check current in-game port labels, draw and server rules, particularly for variants and control outputs. Some catalog entries group cosmetic or DLC variants. Exact costs are available from the linked item references when present.
